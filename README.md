Interactive Certificate & Career DashboardThis project is a single-file, interactive web application designed to help users track their professional certifications, manage their credentials, and explore potential career paths. It is built using HTML, Tailwind CSS for styling, and vanilla JavaScript for all functionality, including data management and dynamic content rendering.Key Features1. At-a-Glance DashboardA top-level overview of all certifications. This section includes a dynamic doughnut chart and key statistics for total, expiring, and expired certificates, providing a quick way to assess your professional status.2. Certificate ManagerA detailed ledger for managing individual credentials. Users can view, filter, and add new certifications using a simple form. All data is handled locally within the browser, meaning the list will reset upon page refresh.3. Career ExplorerAn interactive tool that suggests career paths based on the categories of your certificates. Simply click on a certificate category to see relevant job titles and descriptions.Data StructureThe application's core data is stored in a JavaScript array of objects, which makes it easy to add, update, or remove entries. Below is an example of the data structure used for certificates.let certificates = [
    { id: 1, name: 'Certified Associate in Project Management', organization: 'PMI', expiry: '2026-08-15', category: 'Project Management' },
    { id: 2, name: 'CompTIA Security+', organization: 'CompTIA', expiry: '2025-11-20', category: 'IT' },
    // ... more certificates
];
The career suggestions are stored in a separate object, mapping certificate categories to an array of relevant job roles.How to UseSimply open the certificate_dashboard.html file in any modern web browser to run the application. No server or external dependencies are required. The single-file design makes it easy to share and use.
