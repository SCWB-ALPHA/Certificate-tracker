Certificate & Career TrackerThe Certificate & Career Tracker is a simple, single-file web application that helps you manage your professional certifications. It allows you to track certificate names, issuing organizations, and expiry dates. The app also uses your certification categories to provide personalized career path suggestions, helping you visualize how your credentials can lead to new opportunities.FeaturesAdd, Edit, and Delete Certificates: Easily manage your professional credentials.Expiry Tracking: Certificates are automatically flagged as "Expiring Soon" or "Expired" based on their expiry date.Personalized Career Suggestions: Based on the categories you enter (e.g., IT, HR, Finance), the tool suggests relevant career titles and descriptions.Dynamic Filtering: View certificates by their status (All, Expiring Soon, Expired) or by career category.Printable Ledger: Generate a clean, printable report of your certificates.Responsive Design: The application is built with a mobile-first approach, ensuring it looks and works great on any device.Getting StartedPrerequisitesTo run this application, you need to have Python and Flask installed on your system.pip install Flask
InstallationSave the file: Save the provided app.py code into a single file named app.py.Run the application: Open your terminal or command prompt, navigate to the directory where you saved app.py, and run the following command:python app.py
UsageOnce the application is running, open your web browser and navigate to the local server address, typically http://127.0.0.1:5000. You can then begin adding and managing your certificates.All data is automatically saved to a data.json file created in the same directory as the application.LicenseThis project is licensed under the MIT License.ContributingContributions are welcome!
